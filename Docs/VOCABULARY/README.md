# Vocabulary

One spelling and one meaning per term. Project-management terms that are not specific to this project are in the [Project-Process glossary](../Project-Process/Glossary.md).

## 1. Channel and content
| Term | Meaning |
| :--- | :--- |
| **Source story** | A story found on Chinese social media that a video is based on. Used only as an idea (Clarify C1). |
| **Remake** | A new video built from a source story's idea, with an original script, an AI voice and original or licensed visuals. Not a translation or re-upload. |
| **Niche** | The kind of story the channel publishes (genre), for one audience. |
| **Long video** | A video of several minutes or more, published on the channel's main feed. |
| **Shorts** | YouTube's vertical short videos. |
| **AI voice** | Narration generated by a text-to-speech tool. |

## 2. YouTube terms
Working definitions. The official wording is read and dated in Discover (Clarify C5).
| Term | Meaning |
| :--- | :--- |
| **YouTube Partner Program (YPP)** | YouTube's program that pays channels a share of ad and other revenue once they meet its requirements and pass review. |
| **Reused content** | YouTube's term for content taken from others without significant original change. |
| **Inauthentic content** | YouTube's term for mass-produced or repetitive content. |
| **Copyright claim** | A claim by a rights holder on a video, which can block it or move its revenue. |
| **Strike** | A penalty on a channel; repeated strikes can end the channel. |
| **CTR (click-through rate)** | Share of viewers who click a video after seeing its thumbnail, in percent. |
| **Average view duration** | Average time viewers watch a video, in minutes and seconds. |
| **RPM (revenue per mille)** | The channel's income per 1,000 views, in USD. |

## 3. Project terms
| Term | Meaning |
| :--- | :--- |
| **Gate** | A checkpoint at the end of a step (Clarify, Discover, De-risk, Plan, Implement, Validate). See [Approach §5](../Project-Management/Initiation-phase/Approach.md#5-gates-and-exit-criteria). |
| **Pilot video** | The first video made from story to upload, to measure real hours, cost and quality before a batch. |
| **Spike** | A time-boxed experiment that answers one question (S-n). |
| **Grey area** | An open choice in Clarify (G-n), settled later by evidence. |
| **Epic** | A group of tasks with one measurable outcome (EPIC-nnn). |
| **Proposal** | A request for new scope that waits for the owner's yes or no (PRO-nnn). |
